# Práctica 2 - GitFlow vs Trunk-Based

GitFlow es un modelo de trabajo que utiliza varias ramas para desarrollar nuevas funciones, corregir errores y preparar versiones antes de integrar los cambios a la rama principal. Este flujo es útil cuando un proyecto tiene muchas versiones o un equipo grande de desarrollo.

Por otro lado, Trunk-Based Development consiste en trabajar con ramas pequeñas que se integran rápidamente a la rama principal. Esto permite detectar errores antes y facilita la integración continua.

Para una aplicación web utilizaría Trunk-Based Development porque permite realizar cambios frecuentes, reduce conflictos entre ramas y hace más sencillo mantener el proyecto actualizado.

## Conclusión

Ambos modelos son útiles, pero para una aplicación web elegiría Trunk-Based Development porque facilita la integración continua y reduce los conflictos entre ramas.
